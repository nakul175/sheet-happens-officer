Do not use `npm audit fix --force`, suppress advisories, or present the absence of a demonstrated request path as remediation. Dependency owner: the engineer maintaining SHO; product owner approves exceptions. Record advisory ID, installed/fixed range, reachable path, disposition, retest date and exact tested lockfile with every update.

Native runtime: `src/lib/sho-accept.c` contains the rebuild command and targets Ubuntu 24.04 / GCC 13 / Linux x86-64. `src/lib/shutdown.ts` loads the tracked `.so` through Koffi; macOS test success does not qualify this code. Before approving a release, build in the documented clean Linux toolchain, compare exported symbols and binary/source provenance, and run the shutdown/drain integration tests. Do not silently substitute an unqualified binary or update it from a different architecture. The first byte-identical rebuild gate passed on b2b9c1d9 (GitHub run41637908483); require passing reports for the candidate being considered, including the separate functional checks.

The shared qualification workflow now runs `node scripts/ci/reproduce-native.mjs` before installing packages. It verifies both pinned inputs, rebuilds twice in a temporary directory with GCC 13, requires byte-identical output and matching exported symbols, and preserves `test-results/native-provenance/rebuild.json` plus both rebuilt artifacts. A compiler or binary mismatch fails qualification; investigate it without silently replacing the recorded hash. The tracked source and binary are never overwritten by this check.

`tests/native-shutdown.mode.test.ts` exercises the actual `server.js` entry on two owned Linux loopback processes: a request completes within the drain window, and a deliberately longer request hits the timeout. Both must prove the native signal handler ran, refuse new connections, emit the correct drain outcome, exit with the expected status, and clean up their child. Reports and logs are retained under `test-results/native-shutdown/`. These checks do not certify systemd rollout/rollback, a busy accept queue under load, or a production host. Record a successful exact-revision CI result before treating either native gate as verified.
