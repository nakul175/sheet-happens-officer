# SHO-2595 release checks

This branch is not released. Keep the story awaiting release evidence until the deployment owner records the released SHA, migration outcome and acceptance results.

Apply the additive AuthToken FEED enum / nullable expiry migration before running this build. VERIFY and RESET remain expiring single-use tokens; malformed null-expiry rows fail closed. FEED uses one stable per-user row and SHA-256 hashes only.

Before exposing the feed, the deployment owner must configure every edge/proxy/access logger to redact the entire `/feed/<secret>.ics` path (for example log `/feed/[redacted].ics`) and disable request-path/body capture for token issuance. The app does not log feed secrets; the public URL is itself a credential and default access logs may otherwise record it. Do not put a real feed URL in release evidence, analytics, screenshots, tickets or logs.

After deployment, verify an authenticated person can issue a URL, anonymously subscribe, move a task with versioned Undo, and reset the subscription. Confirm the old URL immediately returns 404, removal of membership hides its events, hidden CRM is absent and deactivation returns 404. Check month/week desktop and phone day list. Record Outlook subscription refresh separately: Outlook may take hours even though the server feed changes immediately. No two-way sync, invitations or reminders are provided.
