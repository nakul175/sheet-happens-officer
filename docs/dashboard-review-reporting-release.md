# SHO-3087–3089 Dashboard, Review and Reporting

Home is a functional dashboard; My tasks remains a distinct route. Legacy Home task deep links redirect to My tasks with their query preserved. Dashboard panels load independently and show unavailable counts as unavailable, with retries. All queries are authenticated, membership scoped and CRM visibility aware; deleted and archived projects are excluded. Approval rows require effective write permission. Activity retains the existing role and task participation policy. Queries are bounded; complete counts are independent of displayed subsets. Project progress uses nondeleted top-level tasks, rounds to the nearest whole percent, and handles zero tasks. Overdue uses IST midnight.

Review combines actionable reasons into one stable queue, deduplicated by entity kind and ID. Existing conversion and idea-drop authorization remain intact. Reporting moves to a separate route while retaining existing API counts, classification, date filters and currency separation. No migrations or provider integrations are introduced.

Validation includes focused component regressions, database authorization/count/pagination/IST cases in the full integration suite, TypeScript, optimized build and the inherited release workflow. Local checks and CI are not production acceptance. Staging, reviewed deployment, exact-revision smoke and rollback evidence remain required before Done. The inherited workflow also declares a separate live-provider gate; its applicability to this UI-only release requires an explicit release-policy decision, rather than silently deleting the gate or requesting a new AI integration.
