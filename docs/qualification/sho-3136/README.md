# SHO-3136 — Approved mascot branding

Base: live `8bd281a7e44b90ffe6974365194d732e5a26a191`.

## Change

Recreates the approved angular white sheet, navy outline, gold fold and oversized
gold spectacles as transparent vector artwork. Half-lidded sideways pupils,
asymmetric brows and a restrained smirk preserve the mature expression. No cap or
concept-board heading is shipped as branding. Original approved PNG references
are retained in `references/`; these are review material, not header assets.

Both light/dark icon paths use the same master. The horizontal lockup includes
the exact product name. Existing 192/512px app icons, Apple icon, maskable icon
and 16/32/48px favicon are regenerated by `node scripts/generate-brand-icons.mjs`.
Tiny variants omit peripheral eye creases; maskable artwork stays in the safe area.

Existing Shell, signin, recovery/verification AuthShell and offline placements
consume these asset paths. Default AuthShell now uses the mascot beside visible
text, rather than shrinking the entire text lockup into a 34px box. Images reserve
dimensions and keep their aspect ratio. Desktop full-width header uses a 40px icon;
intermediate and phone sizes, header height, navigation and controls stay intact.
